# Areas_JaelSantos
Repositorio para el examen de TI
El propósito del proyecto (Areas básica), es la creación de un pequeño programa que realice las áreas básicas de las figuras geometricas.
• Tecnologías utilizadas:
  - Jira para el control de las tareas
  - Java para desarrollo del programa
  - Git Hub para almacenar dicho programa conectado a Jira
• Instrucciones de uso.
 - Primero deberá clonar el repositorio
 - Posteriormente, ejecutar el index.js
 - Finalmente seleccionar que tipo de área desea calcular
